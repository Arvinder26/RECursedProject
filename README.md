# RECurseD

RECurseD is a first-person psychological horror game made in Unity. The game focuses on tension, atmosphere, CCTV monitoring, anomaly events, sound cues, and jumpscare-style horror moments.

The player explores a dark environment while trying to notice strange activity, react to danger, and survive the escalating horror.

## Features

* First-person movement
* CCTV camera system
* Anomaly-based horror events
* Countdown pressure when danger is active
* Directional footstep audio
* Jumpscare and chase moments
* Subtitles for important cues
* Custom 3D assets and animations
* Dark horror atmosphere

## Built With

* Unity
* C#
* Blender
* GitHub

## Gameplay

The player moves through a horror environment and uses CCTV cameras to monitor suspicious activity. Strange events can occur throughout the game, and the player must react before the situation becomes dangerous.

The horror experience is built through:

* Visual changes in the environment
* Audio cues
* CCTV observation
* Timed pressure
* Sudden jumpscare events
* Chase-style encounters

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Arvinder26/RECursedProject.git
```

2. Open Unity Hub.

3. Click **Add Project**.

4. Select the cloned `RECursedProject` folder.

5. Open the project in Unity.

6. Open the main game scene.

7. Press **Play** to run the game.
